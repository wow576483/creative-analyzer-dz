# creative-analyzer-dz

أداة تحليل فيديوهات الإعلانات الصينية وتحويلها إلى **كرياتيفات احترافية مكيّفة للسوق الجزائري** (دارجة + COD + ثقة + توصيل 58 ولاية).

> **الفكرة**: المتحدث في الفيديو المرجعي يقترح طريقة "البيرميوتيشن":
> اكتب 5 Hooks + 5 Bodies + 5 Proofs + 5 CTAs، ثم ادمجهم → ≈ 625 كرياتيف ممكنة.
> هذه الأداة تأخذ فيديو إعلان صيني لمنتج معيّن، وتُخرج لك تلقائياً المكوّنات
> الأربعة (Hook / Body / Proof / CTA) لكل مشهد، ثم تُولّد عشرات السكريبتات
> الجاهزة بالدارجة الجزائرية باستخدام GPT-4o-mini.

---

## ✨ ماذا تفعل الأداة بالضبط؟

أعطها فيديو إعلان صيني `.mp4` → تُخرج لك:

1. **تقطيع المشاهد** (PySceneDetect) مع keyframe لكل مشهد.
2. **تفريغ صوتي** لكل مشهد ([faster-whisper] متعدد اللغات).
3. **وصف بصري** لكل مشهد (GPT-4o-mini Vision: من في الكادر، ما المنتج، نص على الشاشة، مشاعر…).
4. **تصنيف الدور** لكل مشهد: `Hook` / `Body` / `Proof` / `CTA` / `Transition`.
5. **تكييف جزائري** لكل عنصر بـ 3 بدائل بالدارجة.
6. **محرّك Permutation** يدمج Hook×Body×Proof×CTA ويُولّد 5–10 سكريبتات كاملة جاهزة للتصوير.
7. **تقرير** Markdown + HTML + JSON + ملف CSV قابل للنسخ مباشرة.

## 🛠️ الاستعمال

### 1) عبر CLI

```bash
creative-analyzer analyze \
  --video path/to/chinese_ad.mp4 \
  --product "ساعة ذكية رياضية" \
  --price 3500 \
  --old-price 5900 \
  --currency DZD \
  --out runs/run01
```

سيُولِّد:

```
runs/run01/
├── scenes/                  # مقاطع كل مشهد + keyframe
├── transcript.json
├── analysis.json            # المشاهد المصنّفة + الوصف البصري
├── creatives.json           # السكريبتات النهائية بالدارجة
├── report.md
├── report.html
└── creatives.csv
```

### 2) عبر واجهة الويب (Drag & Drop)

```bash
creative-analyzer serve --host 0.0.0.0 --port 8000
```

افتح `http://localhost:8000`، اسحب الفيديو، اكتب اسم المنتج والسعر، اضغط "حلّل".

## 🇩🇿 لماذا "للسوق الجزائري"؟

تحتوي الأداة على قاعدة معرفة (`analyzer/algeria_kb.py`) مبنية على بحث في
أداء الإعلانات في الجزائر، وتُطبَّق هذه القواعد على كل اقتراح:

- **الدفع عند الاستلام (COD)** هو السائد → دائماً اذكره صراحة.
- **اللغة دارجة جزائرية** مع كلمات فرنسية شائعة (`livraison`, `gratuit`, `promo`, `cadeau`).
- **التوصيل لـ 58 ولاية** نقطة بيع قوية.
- **Anchor pricing**: السعر القديم مشطوب + السعر الجديد بارز.
- **Trust signals**: ضمان، استرجاع، شهادات حقيقية، UGC.
- **CTA**: رقم هاتف / واتساب أكثر فاعلية من فورم معقّد.
- **Urgency/Scarcity**: "آخر القطع"، "العرض حتى الليلة".
- **Format**: عمودي 9:16، أول 3 ثوان حاسمة.
- **حساسيات ثقافية**: تجنّب الكحول، الموسيقى الصاخبة، اللباس غير المناسب.
